# Day 39 - Tailwind & Navigate Task

This is a React + Vite + Tailwind CSS project with two pages.

## Run

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Pages and themes

- **Dashboard (`/`)**: light slate background with indigo/violet header, project statistics, and navigation to Services.
- **Services (`/services`)**: dark emerald background with lime accents and responsive service cards.

## Assignment requirements

1. Dashboard page and Services page created as separate React components.
2. `BrowserRouter`, `Routes`, and `Route` navigate between the pages.
3. A shared navbar uses `NavLink`, while dashboard buttons use `useNavigate` and `Link`.
4. Tailwind CSS styles both pages with distinctly different color themes.
5. Tailwind responsive grid, spacing and typography utilities are used.

## Build

```bash
npm run build
```
